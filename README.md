# Knowledge Map v0.2

一个数据驱动的 Incremental / Clicker 知识地图原型。

## 运行

```powershell
npm.cmd install
npm.cmd run dev
```

然后打开终端显示的本地网址（通常是 `http://localhost:5173/`）。

如果 PowerShell 已允许 npm 脚本，也可以直接使用 `npm install` / `npm run dev`。

## v0.2 怎么玩

- 游戏首先是一张大地图，而不是卡片列表。
- 点击地图任意空白处获得“知识”。
- 第一个圆形生产者“学习”一开始就在地图上。
- 攒够知识后点击生产者，右侧面板里购买/升级。
- 生产者达到条件后，相关技能节点自动出现并通过曲线连接。
- 购买技能后会增强生产者或点击收益，并继续解锁后续节点。
- 第二、第三个生产者也可以由前面的技能解锁，知识网络会逐渐向外生长。编辑器支持“掌握某标签技能 N 个”作为解锁条件，所以以后可以直接设置成“掌握 35 个 learning 技能后出现下一个生产者”。

## 地图编辑器

切换到“地图编辑器”：

- 从左侧拖“生产者”或“技能”到地图任意位置。
- 放下后填写 ID、名称、图片、价格、产量/倍率等数据。
- 选择“连接到哪个节点”。技能既可以连接生产者，也可以连接另一个技能。
- 选择出现条件：立即出现、跟随父节点、或资源达到数量。
- 现有节点可以直接拖动重新排布。
- 双击现有节点可编辑或删除。
- Producer 图片可以填写 URL / `/assets/...`，也可以上传自己的图片。
- 内容仍可导入/导出 JSON。

## 架构原则

`graph.parentId` 只负责地图连线与布局；真正的游戏解锁逻辑仍由 `unlockCondition` 决定。这样以后可以重新排地图，而不会破坏游戏规则。

具体见 `ARCHITECTURE.md`。
